# AI Skills Directory

This folder is used to store custom routines, tools, and instructions for the AI assistant. 
You can add markdown files here with specific instructions on how to handle certain tasks, coding patterns, or workflows in this repository. 

## How to use
1. Create a new markdown file (e.g., `release_process.md`)
2. Write down the step-by-step instructions or rules.
3. The AI assistant will be able to read and execute these skills when asked!
